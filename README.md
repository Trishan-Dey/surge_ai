# Surge AI

Surge AI is a custom-built AI assistant that allows users to ask questions and receive intelligent, real-time responses through a simple application interface.

## About the Project

I built Surge AI to create my own AI assistant rather than just using an existing AI website. The main idea was to build a working application where users can enter questions and interact with an AI through a custom interface.

While developing it, I worked on the application interface, AI integration, prompt handling, response processing, and improving the overall user experience.

## Features

* Ask questions and receive AI-generated responses
* Chat-style interface for interacting with the assistant
* Real-time response handling
* Custom application interface
* Ability to continue asking new questions
* Error handling for unsuccessful requests
* Simple and easy-to-use interface

## How It Works

The basic process is:

```text
User
  |
  v
Surge AI Interface
  |
  v
User's Question
  |
  v
AI / API Processing
  |
  v
Generated Response
  |
  v
Surge AI Interface
```

The user enters a question through the application. Surge AI sends the request to the configured AI service, receives the response, and displays it back to the user.

## Running the Project

### Requirements

To run Surge AI, you will need:

* Android Studio
* An Android device or emulator
* Internet connection
* The required API configuration

### Setup

1. Clone the repository.

```bash
git clone https://github.com/Trishan-Dey/surge_ai.git
```

2. Open the project in Android Studio.

3. Allow Android Studio to sync the Gradle files and download the required dependencies.

4. Configure the required API credentials.

5. Connect an Android device or start an Android emulator.

6. Build and run the application.

## API Keys

API keys and other private credentials should never be uploaded to GitHub.

If you are running the project locally, configure the required credentials using a secure method and keep them out of the public repository.
